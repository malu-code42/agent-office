# Rótulos de triagem

Os papéis canônicos da triagem Matt Pocock correspondem diretamente aos rótulos GitHub:

| Papel canônico | Rótulo GitHub | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer precisa avaliar a issue |
| `needs-info` | `needs-info` | Aguardando informações |
| `ready-for-agent` | `ready-for-agent` | Especificada e pronta para agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será implementada |

Rótulos de prontidão não removem dependências nem gates de aceite.
